Purchase order serialization (XML)

What it is for

Saves an issued purchase order to an XML file and verifies it; it also opens a saved XML and compares it with the database.

Who uses it

Owner

Where it is

Purchasing → Order serialization

Step by step

  1. Open Purchasing → Order serialization.
  2. In Serialize, choose the order and press Serialize to XML.... Choose where to save the file; when it finishes, the checks are shown.
  3. In Deserialize, press Open XML file... and choose an XML file. The recovered order and its comparison with the database are shown.
