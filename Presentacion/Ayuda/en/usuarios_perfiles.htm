Users and profiles

What it is for

Creates, edits, deactivates and unlocks users, and builds the profiles (roles) and permission families that define what each one can do. The history keeps the versions of each user. Every user can change their own password.

Who uses it

Administrator

Where it is

Admin → User Management

Step by step

  1. Open Admin → User Management. To create one, press Create User, fill in the data and the role and press Save; the initial password is generated automatically.
  2. To edit, deactivate or unlock, select the user in the grid and use Edit User, Delete User or Unlock.
  3. Profiles: open Admin → Profiles, choose Role or Family, type the name, check the permissions and press Create.
  4. Change the password: User → Change Password.
