Item change log

What it is for

Shows every change to the data of an item (creation, change, deactivation and restoration) with the previous and new value, and lets you go back to a version (CUS-016 and CUS-017). Stock and status are not restored.

Who uses it

Administrator

Where it is

Admin → Change Log

Step by step

  1. Open Admin → Change Log.
  2. Choose the item, the operation and the dates, and press Search.
  3. Select a change: on the right the values are compared, with the modified fields highlighted.
  4. To go back to a version, choose Previous version or Later version, press Restore version and confirm.

Fields and buttons

On screenMeaning
ItemItem to look up, or all.
OperationCreation, change, deactivation or restoration.
Previous value / New valuePrevious and new value of each item data.
Restore versionReturns the item to the chosen version.

Common messages

MessageWhat to do
The start date cannot be later than the end date.Fix the dates.
The item already has that data.That version equals the current one: there is nothing to restore.
Code … is already used by another item.Another item uses that code: change it before restoring.
The change log is not available: the integrity check failed.The history was altered: recalculate the check digits from the login.
