Main menu

What it is for

It is the window from which every function is opened. Each user only sees enabled the options their role allows; the others appear disabled.

Who uses it

All users

Step by step

  1. Choose a menu in the top bar and then the option.
  2. The chosen screen opens inside the main menu. To switch functions, choose another option.
  3. To finish, use Home → Log Out or Exit.
