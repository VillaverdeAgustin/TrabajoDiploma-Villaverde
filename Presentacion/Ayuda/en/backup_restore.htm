Backup and restore

What it is for

Creates a full backup of the ConectAR_DB database and verifies it (CUS-014), and restores a backup (CUS-015). After restoring, the check digits are recalculated and the session is closed.

Who uses it

Administrator

Where it is

Admin → Backup

Step by step

  1. Backup: open Admin → Backup. The SQL Server backup folder is suggested; you can type another server path.
  2. Press Create backup. The file, date, size and verification result are shown.
  3. Restore: open Admin → Restore, choose a backup from the list or a file with Browse....
  4. Press Restore and confirm. When it finishes, log in again.
