Login

What it is for

Identifies the user when the system starts and, before letting them in, checks the integrity of the database (check digits). It is the first screen of the program.

Who uses it

All users

Step by step

  1. Type your user name and password.
  2. Press Sign In.
  3. The user and the database integrity are checked. If everything is fine, the main menu opens with the options your role allows.
  4. If the database has altered tables and you are an administrator, the Database integrity screen opens: you can recalculate the check digits, restore a backup or exit. If you are not an administrator, the system reports that it is not available.

Fields and buttons

On screenMeaning
UserUser name assigned by the administrator.
PasswordYour password. After 3 failed attempts the user is locked.
Sign InStarts the session.
Recalculate(administrator only) Recalculates the check digits of every table.
Restore backup(administrator only) Opens the restore of a backup.
