Usuarios y perfiles

Para qué sirve

Crea, modifica, desactiva y desbloquea usuarios, y arma los perfiles (roles) y familias de permisos que definen qué puede hacer cada uno. El historial guarda las versiones de cada usuario. Cada usuario puede cambiar su propia contraseña.

Quién la usa

Administrador

Dónde está

Admin → Gestión de Usuarios

Paso a paso

  1. Abra Admin → Gestión de Usuarios. Para crear, presione Crear Usuario, complete los datos y el rol y presione Guardar; la contraseña inicial se genera sola.
  2. Para modificar, desactivar o desbloquear, seleccione el usuario en la grilla y use Modificar Usuario, Eliminar Usuario o Desbloquear.
  3. Perfiles: abra Admin → Perfiles, elija Rol o Familia, escriba el nombre, marque los permisos y presione Crear.
  4. Cambiar la contraseña: Usuario → Cambiar Clave.

Campos y botones
