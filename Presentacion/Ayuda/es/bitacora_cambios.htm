Bitácora de cambios de artículos

Para qué sirve

Muestra cada cambio de los datos de un artículo (alta, modificación, baja y restauración) con el valor anterior y el posterior, y permite volver a una versión (CUS-016 y CUS-017). El stock y el estado no se restauran.

Quién la usa

Administrador

Dónde está

Admin → Bitácora de cambios

Paso a paso

  1. Abra Admin → Bitácora de cambios.
  2. Elija el artículo, la operación y las fechas, y presione Buscar.
  3. Seleccione un cambio: a la derecha se comparan los valores, con los campos modificados resaltados.
  4. Para volver a una versión, elija Versión anterior o Versión posterior, presione Restaurar versión y confirme.

Campos y botones

En pantallaQué significa
ArtículoArtículo a consultar, o todos.
OperaciónAlta, modificación, baja o restauración.
Valor anterior / Valor posteriorValor anterior y posterior de cada dato del artículo.
Restaurar versiónDevuelve el artículo a la versión elegida.

Mensajes frecuentes

MensajeQué hacer
La fecha desde no puede ser posterior a la fecha hasta.Corrija las fechas.
El artículo ya tiene esos datos.Esa versión es igual a la actual: no hay nada que restaurar.
El código … ya lo usa otro artículo.Otro artículo usa ese código: cámbielo antes de restaurar.
La bitácora de cambios no está disponible: falló el control de integridad.El historial fue alterado: recalcule los dígitos verificadores desde el login.
