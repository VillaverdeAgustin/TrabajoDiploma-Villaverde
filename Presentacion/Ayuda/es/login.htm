Login

Para qué sirve

Identifica al usuario al abrir el sistema y, antes de entrar, controla la integridad de la base (dígito verificador). Es la primera pantalla del programa.

Quién la usa

Todos los usuarios

Paso a paso

  1. Escriba su usuario y su contraseña.
  2. Presione Iniciar.
  3. Se verifica el usuario y la integridad de la base. Si todo está bien, se abre el menú principal con las opciones que permite su rol.
  4. Si la base tiene tablas alteradas y usted es administrador, se abre la pantalla Integridad de la base de datos: puede recalcular los dígitos, restaurar una copia o salir. Si no es administrador, el sistema informa que no está disponible.

Campos y botones

En pantallaQué significa
UsuarioNombre de usuario que le asignó el administrador.
ContraseñaSu contraseña. Después de 3 intentos fallidos el usuario se bloquea.
IniciarInicia la sesión.
Recalcular(solo administrador) Recalcula los dígitos verificadores de todas las tablas.
Restaurar copia(solo administrador) Abre la restauración de una copia de seguridad.

Mensajes frecuentes

MensajeQué hacer
El usuario ingresado no existeRevise cómo escribió el usuario.
La contraseña ingresada es incorrectaVuelva a escribirla con cuidado: al tercer error el usuario se bloquea.
El usuario se encuentra bloqueado. Contacte al administradorPida al administrador que lo desbloquee desde Gestión de Usuarios.
Sistema no disponible. Contacte al administrador.La base fue alterada. Avise al administrador para que la revise.
