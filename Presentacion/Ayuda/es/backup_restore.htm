Copia de seguridad y restauración

Para qué sirve

Genera una copia de seguridad completa de la base ConectAR_DB y la verifica (CUS-014), y restaura una copia (CUS-015). Después de restaurar se recalculan los dígitos verificadores y se cierra la sesión.

Quién la usa

Administrador

Dónde está

Admin → Copia de seguridad

Paso a paso

  1. Copia: abra Admin → Copia de seguridad. Se propone la carpeta de copias de SQL Server; puede escribir otra ruta del servidor.
  2. Presione Generar copia. Se muestran el archivo, la fecha, el tamaño y el resultado de la verificación.
  3. Restauración: abra Admin → Restaurar copia, elija una copia de la lista o un archivo con Examinar....
  4. Presione Restaurar y confirme. Al terminar, vuelva a iniciar sesión.
